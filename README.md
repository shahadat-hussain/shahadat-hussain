## 👨‍💻 About Me

I'm a **Research Associate at NYU Abu Dhabi** with 6+ years of experience at the intersection of advanced materials engineering and computational science. My work bridges the physical and digital — designing and fabricating architected metamaterials, then applying data science and machine learning to understand and predict their behaviour.

I design, 3D-print, characterise, and computationally analyse **NiTi Shape Memory Alloy TPMS (Triply Periodic Minimal Surface) lattices** — structures where geometry *is* the property. On the code side, I process experimental data with Python and MATLAB, build ML pipelines for materials property prediction, and develop interactive dashboards to communicate research findings.

> *"...because without materials, there is no engineering."*

## 📊 Featured Data Science Projects

### 🚀 [Falcon 9 Booster Landing Prediction](https://github.com/drshahadathussain/capstone-applied-data-science)
> **IBM Data Science Capstone** — Full end-to-end ML pipeline

Predicted SpaceX Falcon 9 first-stage landing success using real-world launch data. Built a complete data science workflow: SpaceX REST API + web scraping → wrangling → EDA → interactive Folium maps + Plotly Dash dashboards → binary classification models (Logistic Regression, SVM, Decision Tree, KNN) with hyperparameter tuning via GridSearchCV.

## 🔬 Research & Domain Expertise

My code and computational work is tightly coupled to physical experimentation in these areas:

| Domain | Focus |
|---|---|
| **Metamaterials / TPMS** | Gyroid, Schwarz-P, and Primitive lattices — computational design, printability analysis, microstructure characterisation |
| **Additive Manufacturing** | Laser Powder Bed Fusion (LPBF/SLM), FDM, SLA — process parameter optimisation, melt pool dynamics, defect analysis |
| **Shape Memory Alloys** | NiTi (Nitinol) and Cu-based SMAs — phase transformation, superelasticity, thermomechanical behaviour |
| **Scientific Computing** | MATLAB & Python for experimental data processing, curve fitting, stress–strain analysis, and ML-aided property prediction |
| **Image Analysis** | SEM/optical micrograph processing — microstructural feature extraction and classification |
